# AI-обробка заявок для Bitrix24

Демо: https://kaybedow.github.io/ai-lead-bitrix24/

Клієнт залишає заявку на сайті. AI читає текст і розуміє що людині треба, наскільки терміново, яка сума і коли дзвонити. Спам відсіюється одразу. В Bitrix24 падає вже заповнений лід на потрібного менеджера, а менеджеру приходить повідомлення в Telegram.

```
Форма -> webhook.php -> AI -> Bitrix24 -> Telegram
```

## Що вміє

- AI повертає JSON з полями: тип, категорія, пріоритет, сума, час дзвінка, коротке резюме. Кожне поле перевіряється в коді, моделі наосліп не довіряємо.
- Спам у CRM не потрапляє, тільки в лог.
- AI не відповів? Лід все одно створиться, просто без розбору.
- Bitrix24 лежить? Заявка не губиться. Вона йде в чергу, менеджер одразу бачить її в Telegram, а `retry.php` дошле в CRM коли той підніметься.
- Клієнт не чекає поки все відпрацює, відповідь приходить одразу (`'async' => true`).
- Менеджер призначається по категорії.
- Без дублів. Якщо клієнт пише вдруге і його лід ще в роботі, заявка додається коментарем, а менеджер бачить «🔁 Повторне звернення». Якщо старий лід вже закритий, створюється новий.

## Безпека

- В AI йде тільки текст заявки. Ім'я та телефон туди не передаються.
- Ключі лежать у `config.php`, він у `.gitignore` і закритий через `.htaccess`. На nginx `.htaccess` не працює, тому конфіг і логи краще винести за `public_html`.
- Вебхук Bitrix24 тільки з правами на CRM.
- Форму приймаємо лише зі своїх доменів (CORS). Не більше 5 заявок з одного IP за 10 хвилин, працює і за Cloudflare. Від ботів приховане поле-пастка.
- Телефон приводиться до `+380XXXXXXXXX`, з тексту прибираються теги.
- Prompt injection: навіть якщо в заявці написати «ігноруй інструкції», модель може тільки повернути JSON, а його ми все одно перевіряємо.
- Все що йде в Telegram екранується. В лозі телефон замаскований.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Демо. Без сервера AI імітується в браузері |
| `webhook.php` | Приймає заявку з форми |
| `lib.php` | AI, Bitrix24, Telegram, черга |
| `retry.php` | Досилає заявки з черги, запускається з cron |
| `config.example.php` | Приклад налаштувань |
| `.htaccess`, `.gitignore` | Закривають конфіг і логи |

## Як підключити

1. Потрібен PHP 8 з `curl`.
2. Скопіюйте `config.example.php` у `config.php` і заповніть:
   - ключ OpenAI
   - вхідний вебхук Bitrix24 (Розробникам → Інше → Вхідний вебхук, права CRM) і ID менеджерів
   - Telegram за бажанням: токен бота від @BotFather і `chat_id`
3. Залийте на сервер `webhook.php`, `lib.php`, `retry.php` і `config.php`.
4. Додайте в cron: `*/10 * * * * php /шлях/до/retry.php`
5. Відправляйте форму сайту на `webhook.php` (JSON або звичайний POST з полями `name`, `phone`, `message`). Щоб демо показувало відповідь AI з реального сервера, впишіть адресу в `API_URL` в `index.html` і поставте `'async' => false`.

Перевірити з консолі:

```bash
curl -X POST https://your-site.com/webhook.php \
  -H "Content-Type: application/json" \
  -d '{"name":"Олег","phone":"+380671234567","message":"Хочу кредит 200 тисяч на авто, терміново"}'
```

## Що можна додати

- Інша модель. Будь-який OpenAI-сумісний API підключається через `'url'` в конфігу, для Claude чи Gemini треба трохи поміняти `ask_ai()`.
- Те саме можна зібрати в n8n: Webhook → OpenAI → HTTP Request в Bitrix24 → Telegram.
