# AI-обробка заявок для Bitrix24

**Демо:** https://kaybedow.github.io/ai-lead-bitrix24/

Заявка з форми на сайті проходить через LLM. AI визначає тип звернення, пріоритет, суму та зручний час дзвінка, а також відсіює спам. Після цього в Bitrix24 створюється вже заповнений лід з потрібним відповідальним, а менеджер отримує повідомлення в Telegram.

```
Форма на сайті -> webhook.php -> LLM (JSON) -> Bitrix24 crm.lead.add -> Telegram
```

## Що вміє

- AI повертає структурований JSON: `is_spam`, `category`, `type`, `priority`, `amount_uah`, `call_time`, `summary`.
- Відповідь моделі нормалізується, а не приймається наосліп.
- Спам не створює лід, лише пишеться в лог.
- Якщо AI недоступний, лід усе одно створюється без розбору.
- Якщо недоступний Bitrix24, заявка не губиться: вона зберігається в черзі, менеджер одразу отримує її в Telegram, а `retry.php` дошле її в CRM, коли та підніметься.
- Клієнт не чекає AI і CRM: відповідь приходить одразу, обробка йде у фоні (`'async' => true`).
- Відповідальний призначається за категорією.
- **Без дублів:** якщо клієнт з таким телефоном уже є і його лід ще в роботі (`crm.duplicate.findbycomm` + статус ліда), нова заявка додається коментарем, а менеджер бачить «🔁 Повторне звернення». Якщо старий лід уже сконвертований або забракований, створюється новий, щоб звернення не загубилось.

## Безпека

- В AI іде лише текст заявки, без імені й телефону.
- Ключі лише в `config.php`, він у `.gitignore`, а `.htaccess` закриває до нього доступ ззовні. На nginx `.htaccess` не працює, тому `config.php` і логи краще тримати поза `public_html`.
- Вебхук Bitrix24 з правами тільки на CRM.
- CORS лише для своїх доменів, обмеження 5 заявок з IP за 10 хвилин (з урахуванням Cloudflare чи проксі), honeypot від ботів.
- Телефон перевіряється та приводиться до формату `+380XXXXXXXXX`, текст обрізається та чиститься від тегів.
- Захист від prompt injection: текст клієнта передається як дані, а кожне поле відповіді AI перевіряється в коді. Навіть якщо модель «зламати», вона не може нічого зробити, крім як повернути JSON, який ми все одно валідуємо.
- Усе, що йде в Telegram, екранується. У лог телефон пишеться замаскованим.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Демо-сторінка. Без сервера відповідь AI моделюється в браузері |
| `webhook.php` | Приймає заявку з форми |
| `lib.php` | AI, Bitrix24, Telegram, черга, спільні функції |
| `retry.php` | Досилає в CRM заявки з черги, запуск з cron |
| `config.example.php` | Шаблон налаштувань |
| `.htaccess`, `.gitignore` | Закривають конфіг, логи й службові файли |

## Як підключити

1. Потрібен PHP 8 з `curl`.
2. Скопіюйте `config.example.php` у `config.php` і заповніть:
   - **OpenAI:** ключ API.
   - **Bitrix24:** вхідний вебхук (Розробникам → Інше → Вхідний вебхук, права CRM) та ID відповідальних.
   - **Telegram (за бажанням):** токен бота від @BotFather і `chat_id`.
3. Покладіть `webhook.php`, `lib.php`, `retry.php` і `config.php` на сервер.
4. Додайте в cron дозавантаження черги: `*/10 * * * * php /шлях/до/retry.php`.
5. У `index.html` впишіть адресу у `API_URL` (для демо з показом відповіді AI поставте `'async' => false`), або надсилайте на неї форму свого сайту (JSON або звичайний POST з полями `name`, `phone`, `message`).

Перевірка з консолі:

```bash
curl -X POST https://your-site.com/webhook.php \
  -H "Content-Type: application/json" \
  -d '{"name":"Олег","phone":"+380671234567","message":"Хочу кредит 200 тисяч на авто, терміново"}'
```

## Як розширити

- Будь-який OpenAI-сумісний API підключається через `'url'` у конфігу. Для Claude чи Gemini достатньо змінити функцію `ask_ai()`.
- Той самий сценарій збирається в n8n: Webhook → OpenAI → HTTP Request (Bitrix24) → Telegram.
