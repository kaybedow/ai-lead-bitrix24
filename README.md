# AI-обробка заявок для Bitrix24

**Демо:** https://kaybedow.github.io/ai-lead-bitrix24/

Заявка з форми на сайті проходить через LLM. AI визначає тип звернення, пріоритет, суму та зручний час дзвінка, а також відсіює спам. Після цього в Bitrix24 створюється вже заповнений лід з потрібним відповідальним, а менеджер отримує повідомлення в Telegram.

```
Форма на сайті -> webhook.php -> LLM (JSON) -> Bitrix24 crm.lead.add -> Telegram
```

## Що вміє

- AI повертає структурований JSON: `is_spam`, `category`, `type`, `priority`, `amount_uah`, `call_time`, `summary`.
- Відповідь моделі нормалізується, а не приймається наосліп.
- Спам не створює лід, лише пишеться в лог.
- Якщо AI недоступний, лід усе одно створюється без розбору, тож заявка не губиться.
- Відповідальний призначається за категорією.
- **Без дублів:** якщо клієнт з таким телефоном уже є (`crm.duplicate.findbycomm`), нова заявка додається коментарем до його ліда, а менеджер бачить «🔁 Повторне звернення».

## Безпека

- Ключі лише в `config.php`, він у `.gitignore`, а `.htaccess` закриває до нього доступ ззовні.
- Вебхук Bitrix24 з правами тільки на CRM.
- CORS лише для своїх доменів, обмеження 5 заявок з IP за 10 хвилин, honeypot від ботів.
- Телефон перевіряється та приводиться до формату `+380XXXXXXXXX`, текст обрізається та чиститься від тегів.
- Захист від prompt injection: текст клієнта передається як дані, а кожне поле відповіді AI перевіряється в коді. Навіть якщо модель «зламати», вона не може нічого зробити, крім як повернути JSON, який ми все одно валідуємо.
- Усе, що йде в Telegram, екранується. У лог телефон пишеться замаскованим.

## Як підключити

1. Потрібен PHP 8 з `curl`.
2. Скопіюйте `config.example.php` у `config.php` і заповніть:
   - **OpenAI:** ключ API.
   - **Bitrix24:** вхідний вебхук (Розробникам → Інше → Вхідний вебхук, права CRM) та ID відповідальних.
   - **Telegram (за бажанням):** токен бота від @BotFather і `chat_id`.
3. Покладіть `webhook.php` і `config.php` на сервер.
4. У `index.html` впишіть адресу у `API_URL`, або надсилайте на неї форму свого сайту (JSON або звичайний POST з полями `name`, `phone`, `message`).

Перевірка з консолі:

```bash
curl -X POST https://your-site.com/webhook.php \
  -H "Content-Type: application/json" \
  -d '{"name":"Олег","phone":"+380671234567","message":"Хочу кредит 200 тисяч на авто, терміново"}'
```

## Як розширити

- Замість OpenAI можна підключити Claude або Gemini. Для цього достатньо змінити функцію `ask_ai()`.
- Той самий сценарій збирається в n8n: Webhook → OpenAI → HTTP Request (Bitrix24) → Telegram.
